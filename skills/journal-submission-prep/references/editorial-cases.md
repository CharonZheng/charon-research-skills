# 历史技术检查案例

以下 38 项来自历史编辑邮件的去标识化提炼，均为检查场景，不是现行期刊政策。仅按当前稿件和官方证据确定适用性。私人邮件、标题、作者及投稿链接未包含在本 skill 中。

| ID | 历史问题 | 检查与处理 |
|---|---|---|
| C01 | 文献 29 无正文引用 | 双向核对文献与引文；引用范围和表格、图注须纳入；不可为补齐而捏造引用位置 |
| C02 | Fig.5 定位不明 | 检查引用、编号、出现位置与插入标记；无依据的位置交作者判断 |
| C03 | 补充图 S1/S2/S7、表 S1 与 Table 3 定位不明 | 分别建立主文与补充材料索引，避免相互误匹配 |
| C04 | 元数据代码库链接无效 | 用户要求查链接时访问公开目标，区分 404、无权限、网络失败；不能仅凭超时判为不存在 |
| C05 | 临床试验注册信息或不适用声明 | 先确认研究是否为临床试验，再处理声明；不得从“缺注册号”推断不适用 |
| C06 | 单位缺城市、国家 | 检查字段，缺值向作者索取，不猜测 |
| C07 | 主章节与小节编号要求 | 根据本刊本轮要求受控修改编号，核对正文内部引用 |
| C08 | 图表须放文末参考文献之后 | 移动时保留对象关系、题注和引用，渲染确认 |
| C09 | 图和表合计最多 5 项 | 按 figure/table 对象和多面板定义计数；超额由作者选择哪些转补充，不能自动删图 |
| C10 | 单独上传利益冲突表 | 查投稿包是否有已完成表格；不得代替作者签名或编造申报 |
| C11 | 表先图后、各项另页 | 检查顺序和分页，不误把跨页长表算多个表 |
| C12 | 提交适用报告清单 | 根据研究设计选清单并核实适用性；定位页码，缺内容不得虚填 |
| C13 | 伦理机构、编号、知情同意或豁免等信息 | 区分缺信息、未开展相关研究、不适用和已批准；依据原始事实安排位置 |
| C14 | Acknowledgements 后单列 Funding | 与 C15 建立冲突案例，不设成无条件默认值 |
| C15 | Funding 不单列，并入 Acknowledgements | 保留来源、稿件和阶段，按当前要求处理 |
| C16 | 利益冲突包含财务/非财务、专利、编辑角色 | 生成待确认字段；不能自动把缺声明填成无冲突 |
| C17 | 图 6 格式不符 | 核对真实文件类型与允许列表，不只重命名扩展名 |
| C18 | Results 小标题不超过 60 字符，含空格 | 按英文字符口径计数，超限报告；改写需核对科学含义 |
| C19 | 主图与每个图标的来源及权限 | 建立逐元素版权记录、图注 credit 与凭证清单，工具名称不等于出版授权 |
| C20 | clean 与 marked-up 分开，上传类型不同 | 校验两个文件内容及修订可见性；记录系统目标文件类型 |
| C21 | 图 1–6 单独上传、多面板合为同图并标记 | 检查文件清单、面板标签、图注描述和引用一致 |
| C22 | 图像至少 300 dpi、清晰可读 | 本历史阈值不能泛化；按实际最终尺寸与像素计算有效分辨率，不能只改 DPI 标签 |
| C23 | 仅允许一级小标题 | 检查真实结构和视觉标题，不能只依据 Word 样式名称 |
| C24 | IRDM 结构，Introduction/Discussion 无小标题，Results/Methods 有小标题 | 按此个案检查顺序和各节规则；不是通用 IMRaD 替换 |
| C25 | 摘要不分小标题，最多 200 词 | 标记计数口径；改结构与压缩语义分开处理 |
| C26 | Limitations/Conclusions 并入 Discussion | 移动而非删去相关研究内容，保留段落对应关系 |
| C27 | 声明顺序与正文位置 | 检查 Data、Code、Acknowledgements、Contributions、Competing Interests 的顺序及条件 |
| C28 | 伦理与同意放 Methods，不能独立为声明节 | 与其他稿件/期刊规定隔离，按有证据的来源执行 |
| C29 | 补充内容合并为单独 PDF，不接收此处 DOCX | 检查真正文件类型、合并顺序、页码和导出后的图表可读性 |
| C30 | Nature 格式参考文献及顺序 | 当前样式另查官网；校验引用链，不能全局机械删除 DOI 或重排后不更新正文 |
| C31 | 系统缺 Code 独立字段，要求并入 Data | 交付系统填写文本并比对正文；没有实际系统状态则标“未检查” |
| C32 | 图片文件名缺图号 | 建立可追踪重命名映射并同步清单，保留原件 |
| C33 | 公式依次 (1)、(2)…，不接受子编号 | 检查并联动正文交叉引用与 Word 域，不能只改显示数字 |
| C34 | Appendix 改为 Supplementary Information | 连同正文引用、标题、文件名更新；保留旧新名称对应 |
| C35 | Rebuttal 只含完整审稿意见及审稿回复，编辑回复放 Cover letter | 依此本轮要求分流；该邮件还要求文档中不写技术检查回复，不可硬性生成通用回复信 |
| C36 | Supplementary Figure/Table/Note/Movie/References 的命名 | 标签与正文引用一起检查，不能仅全文替换“S” |
| C37 | 不允许脚注 | 先区分正文脚注、表下注释和引文脚注；按来源确定范围并检查合并后的语义 |
| C38 | 通讯作者以星号标出 | 依据作者事实记录检查，不自动改变通讯作者身份 |

优先回归：漏引文献与图、图表合计超限、Funding 冲突、未确认伦理事实、补充命名联动、clean/marked 区分、通讯作者星号。检测和修复是两步，不能为消除告警捏造事实或引用。
