# 编辑与验证

Word 先记录源文件哈希和 ZIP 清单，在副本内定向改段落属性/结构，检查引文域、书签、浮动图、表格、OMML、批注和修订。不要用 paragraph.text 重写整段来调字体，避免损坏字段、超链接和公式。数字引文、统计区间及表格值需区分，不能全局正则替换。

LaTeX 保留 .tex/.bib 与关系文件，用官网 class/style 编译并检查输出。当前脚本不编辑 LaTeX。PDF-only 可审计文字/版面；缺源稿不能声称无损恢复 Word，需取得源文件或明确接受重建。

章节移动保留 sectPr、图片关系和正文引用，检查页眉页脚；超限图表由作者决定，不能自行删证据。摘要压缩、标题改写属于内容编辑，要保留科学含义、条件和数值并报告。

`format` 仅改现有正文、页眉页脚和脚注尾注故事部件允许的段落/文本 run 格式及正文节页边距，保留其他 ZIP 成员字节。表格逐段显式允许后可改文字属性，不能改网格/行列。不动 OMML 字体，不重排章节、不接受修订、不自动修改 styles.xml。

`verify` 对改变的现有正文故事部件排除允许的格式属性后做规范化比较，其他成员逐字节比较；新增/删除部件仍拒绝。文字、字段、公式、对象或其他成员改变将失败。它不证明显示效果一致或期刊规则正确。基础格式独立回读和全段落契约见 [基础格式](formatting.md)。

有意改文将导致 strict verify 失败。按具体授权审查差异，另检查数值、表格、引用映射和对象完整性，不能将失败伪改成通过。

最终文件使用当前环境实际可用的渲染器转 PDF/逐页图并检查全部页面；有 documents/pdf skill 时读其依赖与渲染说明。不要硬编码开发机器路径。缺渲染器标视觉未检查，不以 XML/对象计数替代。修改后必须重新渲染。
